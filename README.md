# 美容室POPII

Cloudflare Pages向けの静的サイト。

ソース管理: https://github.com/crestix-company/popii （`main` ブランチ）

## 公開設定

- Framework preset: None
- Build command: `node scripts/verify.mjs`
- Build output directory: `dist`
- Root directory: このプロジェクトのルート
- 環境変数・サーバー・データベース: 不要

Cloudflare PagesのDirect Uploadの場合は `dist` の中身をアップロードしてください。先頭に `dist/` が入らないようにしてください。トップの `index.html` と `menu/index.html`、`access/index.html` をそのまま配信します。SPAリダイレクトは不要です。

## ローカル表示

`python3 -m http.server 3002 --bind 127.0.0.1 --directory dist`

## 掲載内容

一次資料: 指定ヒアリングシート「ポピー美容院」、指定Driveフォルダの6枚の実写真。

料金・道順・席数・予約条件の照合先（2026-09-17確認）:
- https://beauty.hotpepper.jp/slnH000480498/
- https://beauty.hotpepper.jp/slnH000480498/coupon/

独立したロゴデータは資料フォルダにありません。店名は文字組みで表現し、既存ロゴと称した創作はしていません。

`hero-portrait.webp` と `short-bob.webp` はAI生成イメージです。店舗・スタッフ・来店客・施術実績ではありません。その他の写真は支給された実写真です。ユーザーの指定により、サイト上には生成写真を理由とした注記を表示しません。素材の由来は非公開の制作記録で管理します。

素材の管理記録・元資料・確認用ファイル・配布用ZIPはローカルで管理し、このリポジトリには含めません。

住所はヒアリングシートとHOT PEPPER Beautyに合わせて「藤倉3丁目6-30」を採用しています。Googleマップの同一店舗（同名・同電話番号）には「6-29」と表示されるため、地図サービス側の情報は別途店舗側で確認してください。サイトからはGoogleマップの店舗検索を開きます。
